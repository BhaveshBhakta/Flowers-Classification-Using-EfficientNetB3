# 🌸 Flowers Classification Using Transfer Learning

## 📌 Project Overview

This project focuses on multi-class image classification of flowers into 5 distinct categories using advanced Convolutional Neural Networks (CNNs). It leverages **EfficientNetB3** and **VGG16** as base models for transfer learning to achieve high accuracy on the Flowers Recognition dataset from Kaggle.

---

## ⚙️ Technical Highlights

- **Dataset**: [Flowers Recognition](https://www.kaggle.com/datasets/alxmamaev/flowers-recognition)
- **Classes**: 5 flower categories — daisy, dandelion, rose, sunflower, tulip
- **Image Size**: Resized to 224×224
- **Techniques Used**:
  - Transfer learning with pretrained CNNs
  - Data augmentation for improved generalization
  - Visualization of class distributions and training progress

---

## 🎯 Purpose and Applications

### Purpose:
To explore deep learning-based classification for floral image datasets using modern CNN architectures.

### Applications:
- **Botanical Research**: Automatic flower classification from field images.
- **Educational Tools**: Assist biology students in plant species recognition.
- **Mobile Apps**: Power real-time plant/flower recognition apps.
- **Agriculture**: Flower sorting in greenhouse or crop monitoring systems.
